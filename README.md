# Friendly Phantoms

**Phantoms will no longer annoy you, but you can still get their membranes.**

A tiny Fabric mod: phantoms stop targeting and attacking players. They still
spawn and can be killed, so phantom membranes remain farmable.

Built for Minecraft 1.20 – 1.21.8 (Fabric, Java 17/21) from one shared source
via [Stonecutter](https://stonecutter.kikugie.dev/). `./gradlew build` compiles
every version. ModMenu is optional.
